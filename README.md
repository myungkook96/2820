# PHOTO VOICE

사진 한 장을 올리면, 스크롤을 멈추게 하는 스레드(Threads) 글을 **5가지 결**로 만들어 줍니다.

**→ [바로 사용하기](https://myungkook96.github.io/2820/)**

목표는 '잘 쓴 글'이 아니라 '반응이 오는 글'입니다. 다섯 개의 톤은 각각 노리는 반응이 다릅니다.

| # | 톤 | 노리는 반응 |
|---|---|---|
| 1 | 담백한 관찰자 | 저장 · 리포스트 |
| 2 | 조용한 고백 | 팔로우 |
| 3 | 한 줄 통찰 | 리포스트 |
| 4 | 대화 초대 | 댓글 |
| 5 | 짧은 이야기 | 링크 공유 |

## 쓰는 법

1. 페이지를 열고 상단에 본인의 Anthropic API 키를 넣은 뒤 **저장**을 누릅니다.
2. 사진을 올립니다 — 드래그앤드롭 · 클릭 선택 · `Ctrl`/`Cmd` + `V` 붙여넣기 모두 됩니다.
3. 상황 / 화자 / 길이를 고르고, 추가 맥락을 한 줄 적은 뒤 **글 5개 만들기**.

추가 맥락 한 줄("3년 다닌 회사 마지막 출근길에 찍었어요")이 결과의 진정성을 가장 크게 좌우합니다.

## API 키에 대해

- 키는 **사용자 브라우저의 localStorage에만** 저장됩니다. 이 저장소나 어떤 서버로도 전송되지 않습니다.
- 브라우저에서 Anthropic API를 직접 호출하며, 호출 비용은 키 소유자에게 청구됩니다.
- 공용 PC에서는 사용 후 키 입력칸을 비우고 **저장**을 눌러 삭제하세요.

## 만듦새

- `index.html` **단일 파일**. CSS·JS 전부 인라인, 외부 CDN·라이브러리·프레임워크 **0개**.
- 순수 HTML / CSS / Vanilla JS. 빌드 단계 없음 — 파일을 더블클릭해도 그대로 돌아갑니다.
- 업로드한 이미지는 브라우저에서 **긴 변 1568px로 리사이즈** 후 base64 변환해 전송합니다(토큰 절약).
- 응답 JSON 파싱에 실패하면 1회 자동 재시도하고, 그래도 실패하면 모델의 원문을 그대로 보여 줍니다.
- 모바일 우선 반응형 · 다크 테마.

## 기능

- 결과 카드마다 글자 수 카운터(500자 초과 시 빨간색), `복사`, 해당 톤만 다시 쓰는 `이 결로 다시`
- 접힘식 `첫 댓글 제안` — 스레드에 이어 붙일 자답 한 줄
- `전체 복사` / `초기화`, 최근 생성 3건 로컬 히스토리
